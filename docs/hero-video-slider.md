# Видео на главной: слайдер в шапке и карточки категорий

Раздел админки: **Главная (блоки) → Слайдер с видео** (`/admin/hero-slides`).

Два независимых варианта, включаются переключателями (можно любой или оба сразу):

1. **Слайдер в шапке** — видео на первом экране. Каждый ролик отдельный слайд со своей вкладкой, заголовком,
   подписью и кнопкой; обычная шапка (из «Hero (шапка)») становится ещё одной вкладкой и ставится до или после видео.
2. **Карточки категорий под шапкой** — блок «Обучение по категориям»: по карточке на каждый ролик.

Если слайдов с видео нет (или все выключены), главная выглядит как раньше.

## Инструкция для администратора

Эта же инструкция лежит прямо на странице «Слайдер с видео» (раскрывающийся блок вверху).

1. **Добавить слайд**: внизу нажмите «Добавить слайд», появится карточка.
2. **Что рядом с текстом**: видео, фото или ничего. **Выбрать файл**: «Выбрать видео» или перетащите файл в рамку. Подойдёт любой ролик, хоть 100 МБ: он сожмётся сам.
   Дождитесь, пока полоска дойдёт до конца и появится «Видео загружено», вкладку не закрывайте.
3. **Тексты**: «Название вкладки» это короткая надпись на переключателе (например, «Категория A»), «Заголовок» и
   «Подпись» видны на слайде. Кнопка не обязательна: она появится, только если заполнены и текст, и «куда ведёт».
4. **Как показывать**: справа живой предпросмотр (кнопки «ПК» и «Телефон»), меняйте настройки и смотрите результат.
5. **Сохранить**: зелёная кнопка внизу. Пока не нажали, на сайте ничего не меняется.

Порядок вкладок меняется перетаскиванием карточки за кнопку со стрелками. «Показывать» выключает слайд без удаления.
«Где показывать видео» включает слайдер в шапке и/или карточки под шапкой (можно оба).

## Что настраивается у слайда

| Поле | Значения |
|---|---|
| Что рядом с текстом | видео, фото или ничего (тогда слайд только с текстом); всё необязательно |
| Фон слайда | своё фото (необязательно). Нет: у слайда с видео размытый кадр из видео, у остальных фон основной шапки |
| Название вкладки, заголовок, подпись | текст |
| Кнопка | текст и ссылка из списка (тот же список, что в «Hero (шапка)»); показывается, только если заполнено и то и другое, иначе слайд просто без кнопки |
| Пропорции рамки | как в видео, 9:16, 4:5, 1:1, 4:3, 16:9 |
| Как вписать видео | обрезать по рамке или показать целиком с размытыми полями |
| Где видео | справа, слева, фоном на всю шапку (только для горизонтального видео) |
| Размер видео | маленькое, среднее, большое |
| Выравнивание текста | по горизонтали: слева / по центру / справа; по высоте: сверху / по центру / снизу |
| Показывать | вкл/выкл; порядок — перетаскиванием |

Стрелки слайдера на компьютере появляются, только когда мышь рядом с краем шапки (в зоне заметно больше самой стрелки),
на телефоне и планшете стрелок нет: листают свайпом и вкладками.

## Как работает загрузка

Файл выбирается в админке, дальше всё делает браузер (WebCodecs, библиотека [mediabunny](https://mediabunny.dev),
лежит в `public/adminpanel/js/vendor/`, лицензия MPL-2.0):

1. ролик перекодируется в H.264/AAC (MP4, метаданные в начале файла) так, чтобы уложиться в лимиты сервера;
2. делается короткое (≈8 с) немое превью для автозапуска в шапке и обложка из кадра;
3. на сервер уходят **только** сжатые файлы (например, 98 МБ → 13 МБ). Исходник остаётся у админа на компьютере.

Работает в Chrome и Edge. В браузере без WebCodecs загрузятся только небольшие MP4, остальное будет понятная ошибка.

### Фото

Фото (рядом с текстом и фон слайда) тоже уменьшаются в браузере до загрузки: рядом с текстом до 1600 px и ~1 МБ,
фон до 2560 px и ~1,5 МБ (общий ресайзер `image-autoresize.js`). Если файл всё же обошёл браузер, сервер сам
уменьшает его через GD до 2560 px по длинной стороне (с учётом поворота из EXIF, PNG остаётся PNG), принимает
JPEG/PNG/WebP до 6 МБ (`HERO_IMAGE_MAX_MB`) и до 40 млн пикселей.

### Что проверяет сервер (даже если обойти браузер)

Сервер не верит браузеру: размер кадра, длительность и битрейт читаются из самого присланного MP4
(`app/Support/Mp4Info.php`, без ffmpeg). Не пройдут:

- не MP4 по содержимому, битый файл, нет видеодорожки, файл больше 30 МБ;
- кадр больше 1920 px по длинной стороне, ролик длиннее 15 минут, средний битрейт выше 4,5 Мбит/с
  (то есть «просто большой файл», не прошедший сжатие);
- превью длиннее 20 с или больше 960 px, обложка не JPEG или больше 2000 px.

Пределы настраиваются в `config/hero_slider.php` (переменные `HERO_VIDEO_*` в `.env`). Загруженное, но не
сохранённое в слайд, удаляется через сутки; одновременно хранится не больше 12 таких загрузок. Перекодирования
на сервере нет: оно требовало бы ffmpeg и долгого запроса, а лимиты PHP (`upload_max_filesize`, `post_max_size`)
всё равно не пропустят тяжёлый файл.

## Выкладка на сервер

```bash
git pull origin main
composer dump-autoload -o
php artisan migrate --force      # таблица hero_slides и новые поля hero_settings
npm ci && npm run build          # public/build в git не лежит
```

Лимиты PHP (для mod_php: `/etc/php/8.1/apache2/php.ini`), без них длинные ролики не влезут:

```ini
upload_max_filesize = 32M
post_max_size = 64M
```

и `sudo systemctl restart apache2`. Если лимиты меньше, админка честно скажет, на сколько секунд можно сократить ролик.
Папка `storage/app/public` должна быть доступна по `/storage` (`php artisan storage:link`).

## Где лежат файлы

`storage/app/public/hero-slides/{id}/` — `video-*.mp4`, `preview-*.mp4`, `poster-*.jpg`; временные загрузки в
`hero-slides/tmp/`. При замене видео и удалении слайда старые файлы удаляются.

## Отсечь тяжёлый файл ещё до PHP (по желанию, Apache)

PHP узнаёт о слишком большом теле запроса только после его получения. Чтобы Apache обрывал такие загрузки сразу,
в конфиге сайта для адреса загрузки можно задать предел тела запроса (чуть выше `post_max_size`):

```apache
<Location "/admin/hero-slides/upload">
    LimitRequestBody 70000000
</Location>
```
